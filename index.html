JAVA LAB

Week 1

Questions and Solutions

↓ Download Complete

Questions

  1. Write a Java program to display "Hello, Java!" and demonstrate the basic structure of a Java program.
  2. Write a Java program to declare variables of different primitive data types and display their values.
  3. Write a Java program to perform arithmetic operations on two integer variables.
  4. Write a Java program to perform arithmetic operations on floating-point numbers.
  5. Write a Java program to demonstrate character data type by displaying a character and its corresponding ASCII/Unicode value.
  6. Write a Java program to demonstrate Boolean variables and Boolean expressions.
  7. Write a Java program to declare and initialize different types of variables and display their values.
  8. Write a Java program to swap the values of two variables using a temporary variable.
  9. Write a Java program to demonstrate automatic widening type conversion.
  10. Write a Java program to demonstrate explicit narrowing type casting.
  11. Write a Java program to convert a character to its ASCII/Unicode value and vice versa.
  12. Write a Java program to check whether a number is even or odd using if-else.
  13. Write a Java program to find the largest of two numbers using if-else.
  14. Write a Java program to demonstrate Java reserved keywords.
  15. Write a Java program to demonstrate the for loop by displaying numbers from 1 to 10.
